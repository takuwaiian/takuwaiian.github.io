# ポートフォリオサイト

AI業務自動化の実績集（静的HTML1枚構成）。

| パス | 用途 | 連絡先 |
|---|---|---|
| `/` | X・紹介・直接の問い合わせ向け | あり（メール・X） |
| `/works/` | クラウドソーシング提出用 | **なし** |

`/works/` からは `/` へリンクしていない。プラットフォーム提出時に
外部への誘導と受け取られないようにするため、意図的に分離している。

## 更新のしかた

1. `index.html`（と必要なら `works/index.html`）を編集
2. `git add -A && git commit -m "..." && git push`
3. 1〜2分でGitHub Pagesへ反映される

ケースを追加したら、本文冒頭の「最終更新：YYYY年M月」も必ず書き換える。
（`05_ポートフォリオ格納ルール` と同じ運用）

## 注意

- 掲載する実績はすべて匿名化する。企業名・個人情報は載せない
- デモは架空データによる自主制作サンプルであることを明記する
